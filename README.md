# 🎮 KorePilot

โปรแกรมช่วยเล่น (บอท) Ragnarok เซิร์ฟ **Eternal Origin** ผ่าน OpenKore — คุมง่ายผ่านหน้าจอ ไม่ต้องแตะไฟล์ config เอง

> ⚠️ **คำเตือน:** การใช้บอทมักผิดกฎของเซิร์ฟเวอร์และ**อาจโดนแบนบัญชี** ใช้ด้วยความรับผิดชอบของตัวเอง โปรแกรมนี้อยู่ในช่วงทดลอง (BETA)

---

## 📥 การติดตั้ง

1. ไปที่หน้า **[Releases](../../releases)** แล้วโหลดไฟล์ `KorePilot-Setup-x.x.x.exe` ตัวล่าสุด
2. ดับเบิลคลิกเพื่อติดตั้ง
3. ถ้า Windows ขึ้นเตือน **"Windows protected your PC"** (SmartScreen) เพราะยังไม่ได้เซ็นใบรับรอง — กด **More info → Run anyway** (โปรแกรมปลอดภัย เป็นแค่การเตือนสำหรับโปรแกรมใหม่)
4. เปิดโปรแกรมจากไอคอน KorePilot บนเดสก์ท็อป

---

## 🚀 วิธีใช้งาน

### 1. ล็อกอิน (แท็บแรก)
- กรอก **ชื่อผู้ใช้ / รหัสผ่าน** บัญชี Eternal Origin ของคุณเอง (ถ้ายังไม่มี สมัครที่เว็บเซิร์ฟก่อน)
- เลือก **ช่องตัวละคร**
- วาง **🔑 คีย์ลิขสิทธิ์** ที่ได้รับ แล้วกด **บันทึกคีย์**
- กด **บันทึกล็อกอิน**

> **ต้องมีคีย์ลิขสิทธิ์ถึงจะเข้าเกมได้** — ถ้าไม่มีหรือคีย์หมดอายุ บอทจะเชื่อมต่อไม่ได้ ขอคีย์จากผู้ให้บริการ

### 2. ตั้งฟาร์ม (แท็บ 🗺️)
- ใส่ **แมพที่จะฟาร์ม** เช่น `prt_fild08`
- ติ๊ก **ตีมอนทุกตัว** / **กินโพชั่นอัตโนมัติ** / **ฝากคลังเมื่อของเต็ม** ตามต้องการ
- กด **บันทึกการฟาร์ม**

### 3. เริ่มบอท
- กดปุ่ม **▶ เริ่มบอท** ที่มุมล่างซ้าย
- โปรแกรมจะพาไปแท็บ **📡 สถานะสด** อัตโนมัติ — ดู HP/SP, มินิแมพ (ตัวเรา/มอน/NPC), และ log ว่าบอทกำลังทำอะไร
- กด **■ หยุด** เพื่อหยุด

### 4. เจอปัญหาระหว่างเล่น
- ไปแท็บ **🩺 แก้ปัญหา** — โปรแกรมจะอธิบายอาการเป็นภาษาไทย + บอกวิธีแก้

---

## 🔄 การอัปเดต

โปรแกรม**เช็คเวอร์ชันใหม่ให้อัตโนมัติ** เมื่อมีอัปเดตจะขึ้นแถบแจ้งที่มุมล่างซ้าย กด **"รีสตาร์ทเพื่อติดตั้ง"** ได้เลย ไม่ต้องโหลดใหม่เอง
